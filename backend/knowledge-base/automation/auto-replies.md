# Keyword Auto-Replies

## What are Auto-Replies?
Keyword Auto-Replies automatically answer incoming customer WhatsApp messages 24/7 without requiring a human agent to be online.

## Matching Types
- **Exact Match**: Triggers only when the customer message equals the keyword exactly (e.g. `OFFER`).
- **Contains**: Triggers if the customer message contains the word anywhere (e.g., "Tell me about your *OFFER*").
- **Starts With**: Triggers if the message begins with the keyword.

## Plan Rule Limits
- **Free Trial**: 0 Auto-Reply rules.
- **Starter Growth**: Up to 5 active rules.
- **Pro Automation**: Up to 25 active rules.
- **Enterprise Scale**: Unlimited rules.
