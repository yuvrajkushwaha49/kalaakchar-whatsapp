# Workflow Automation & Webhooks

## External Triggers & API
- **Webhooks**: Stream real-time events (`message_received`, `delivery_receipt`, `template_approved`) to your external CRM or ERP system.
- **REST API**: Discard manual entry by programmatically sending automated notifications (e.g. Shopify order confirmations, Razorpay payment receipts) via our `/api/campaigns` and `/api/whatsapp/messages` endpoints.
- Available on **Pro Automation** and **Enterprise Scale** plans.
