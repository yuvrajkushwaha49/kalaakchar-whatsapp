# Authentication Templates & One-Tap OTP

## Overview
Authentication templates provide secure OTP delivery with native WhatsApp buttons:
- **Copy Code Button**: Copies the numeric OTP to the user clipboard in a single tap.
- **One-Tap Autofill**: Automatically transfers the code to your Android/iOS mobile application.
- Expiration warnings can be optionally included (e.g., "This code expires in 10 minutes").
