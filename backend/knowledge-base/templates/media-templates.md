# Media Templates (Image, Video & Document)

## Supported Media Types
1. **Images**: PNG, JPG/JPEG (up to 5 MB). Ideal for festive greeting flyers, restaurant menus, product catalogues.
2. **Documents**: PDF (up to 100 MB). Ideal for sending invoices, price sheets, insurance policies, brochures.
3. **Videos**: MP4 (up to 16 MB). Ideal for quick product walkthroughs, teasers, event invites.

## Header Mapping in Campaigns
When sending a media template in a broadcast campaign, the user can upload a media file or provide a public HTTPS URL which Meta caches and distributes to recipients.
