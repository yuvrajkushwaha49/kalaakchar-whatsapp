# Contact CSV & Excel Import / Export

## Importing Contacts
1. Go to **Contacts** ➔ Click **Import Contacts**.
2. Upload a `.csv` or `.xlsx` file (up to 50 MB, streaming chunk processor handles up to 100,000 rows).
3. Map columns: Phone Number (mandatory), Name, Email, Tags.
4. Duplicate phone numbers are automatically detected and updated rather than duplicating records.

## Exporting Contacts
Click **Export All Contacts** to download a CSV backup including current tags and opt-in status.
