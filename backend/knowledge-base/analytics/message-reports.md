# Message Delivery & Status Tracking

## WhatsApp Status Indicators
- **Sent (Single tick)**: Message successfully sent through Meta Cloud API.
- **Delivered (Double grey ticks)**: Delivered to recipient's active WhatsApp client.
- **Read (Double blue ticks)**: Recipient opened the chat and read the message.
- **Failed (Red exclamation)**: Message failed to deliver. Hovering over the error shows the Meta error reason code.
