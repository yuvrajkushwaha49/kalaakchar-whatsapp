# Common Platform Errors & Solutions

## Common Scenarios
1. **Invalid Phone Number**: Ensure the phone number includes the international country code without plus signs or spaces (e.g. `919811122233` for India).
2. **Quota Exceeded**: If the campaign dispatch fails with "Monthly message quota exceeded", upgrade your subscription plan in **Billing & Plans**.
3. **Session Window Expired**: If sending a free-form message in Team Inbox returns an error, the 24-hour customer window has closed. Send an approved template instead.
4. **Login / CORS Errors**: Ensure you access the application via `https://whatsapp.kalaakchar.in`.
